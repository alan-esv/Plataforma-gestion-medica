# Plataforma Web de Gestión Médica

Plataforma web Full-Stack diseñada para optimizar la programación de citas y reducir tiempos de espera en centros de salud. El sistema centraliza la información y facilita la interacción entre pacientes y el centro médico, evitando la pérdida de historiales.

## ✨ Características Principales

* **Autenticación Basada en Roles:** Sistema de inicio de sesión con enrutamiento y acceso seguro diferenciado para usuarios estándar y administradores.
* **Gestión de Citas:** Formularios dinámicos interactivos para la captura de datos del paciente, historial de padecimientos y selección de médicos por especialidad.
* **Diseño Responsivo:** Interfaz adaptable a múltiples resoluciones móviles y de escritorio.

## 🛠️ Stack Tecnológico

* **Frontend:** HTML5, CSS3, JavaScript (jQuery, Owl Carousel), Bootstrap.
* **Backend:** PHP.
* **Base de Datos:** MySQL.
